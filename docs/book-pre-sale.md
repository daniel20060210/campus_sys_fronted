# 图书预售业务文档

## 1. 业务概述

图书预售是校园食堂平台推出的限时优惠活动，允许管理员创建一个统一的预售活动周期，在该周期内用户可以以优惠价格预购图书。

**核心特点：**
- 单一活动模式：整个预售期只有一个活动，由管理员手动控制开始和结束
- 批量图书：一个活动可以包含多本参与预售的图书
- 状态控制：通过开始/结束按钮手动控制活动生命周期

## 2. 功能模块

### 2.1 活动管理

| 功能 | 说明 |
|------|------|
| 创建活动 | 首次使用时自动创建默认预售活动 |
| 编辑活动 | 支持修改活动名称、描述、开始/结束时间 |
| 开始活动 | 手动触发，活动状态变为"进行中"，用户可下单 |
| 结束活动 | 手动触发，活动状态变为"已结束"，用户无法下单 |
| 活动状态 | 未开始 → 进行中 → 已结束 |

**活动字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 活动名称，如"2026春季图书预售" |
| description | string | 否 | 活动描述，展示优惠信息 |
| startTime | timestamp | 是 | 活动开始时间 |
| endTime | timestamp | 是 | 活动结束时间 |
| status | number | 系统 | 0=未开始 1=进行中 2=已结束 |
| totalOrders | number | 系统 | 活动总订单数 |
| totalRevenue | number | 系统 | 活动总收入 |

### 2.2 图书管理

| 功能 | 说明 |
|------|------|
| 添加图书 | 向活动中添加参与预售的图书 |
| 编辑图书 | 修改图书信息（书名、价格、库存等） |
| 删除图书 | 从活动中移除图书 |
| 查看列表 | 查看所有参与预售的图书 |

**图书字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| bookName | string | 是 | 图书名称 |
| author | string | 是 | 作者 |
| publisher | string | 否 | 出版社 |
| coverUrl | string | 否 | 封面图片URL |
| originalPrice | number | 是 | 原价 |
| preSalePrice | number | 是 | 预售优惠价 |
| stock | number | 是 | 库存数量 |
| soldCount | number | 系统 | 已售数量 |

### 2.3 数据统计

| 指标 | 说明 |
|------|------|
| 总订单数 | 活动期间累计订单数量 |
| 总收入 | 活动期间累计销售额 |
| 活动时长 | 活动持续天数 |
| 参与图书 | 参与预售的图书种类数 |

## 3. 业务流程

### 3.1 活动生命周期

```
[创建活动] → [添加图书] → [开始活动] → [用户下单] → [结束活动] → [活动结束]
     ↓              ↓            ↓            ↓            ↓
  未开始        未开始       进行中       进行中        已结束
```

**状态流转：**

1. **未开始**：管理员可以编辑活动信息、添加/编辑/删除图书
2. **进行中**：
   - 活动开始时间已到达，管理员点击"开始活动"按钮
   - 用户可以浏览图书并下单购买
   - 管理员可以继续添加/编辑/删除图书
3. **已结束**：
   - 管理员点击"结束活动"按钮，或活动结束时间到达
   - 用户无法再下单
   - 图书管理功能禁用（防止活动结束后误操作）

### 3.2 用户视角

1. 用户进入图书预售专区
2. 查看活动详情（进行中的活动）
3. 浏览参与预售的图书列表
4. 选择图书下单购买（按预售价结算）
5. 等待图书配送/自提

## 4. 业务规则

### 4.1 活动规则

- 每个时刻只能有一个进行中的预售活动
- 活动未开始时，管理员可以设置活动时间和图书
- 活动进行中，管理员可以随时开始或结束
- 活动结束后，所有图书自动变为不可购买状态
- 活动开始后，系统自动将开始时间更新为实际开始时间

### 4.2 图书规则

- 图书预售价必须低于原价
- 库存为0时，用户无法下单
- 活动未开始和进行中时，可以添加/编辑/删除图书
- 活动已结束时，禁用图书管理功能
- 新添加的图书初始销量为0

### 4.3 价格规则

- 原价：图书的原始销售价格
- 预售价：活动期间的优惠价格，用户按此价格购买
- 折扣 = (预售价 / 原价) × 100%

## 7. 典型使用场景

### 场景一：创建新活动

1. 管理员进入"图书预售"页面
2. 系统自动创建默认活动（如无活动）
3. 点击"编辑活动"，设置活动名称、描述、时间
4. 点击"添加图书"，逐个添加参与预售的图书
5. 设置完成后，点击"开始活动"

### 场景二：活动期间调整

1. 活动进行中，管理员发现某图书库存不足
2. 点击该图书的"编辑"，修改库存
3. 或者点击"添加图书"添加新品
4. 或者删除滞销图书

### 场景三：结束活动

1. 活动到期或需要提前结束
2. 点击"结束活动"按钮
3. 系统提示确认
4. 确认后活动状态变为"已结束"
5. 用户无法再下单

## 10. 注意事项

1. **活动唯一性**：系统只支持一个预售活动，避免活动冲突
2. **时间设置**：活动开始时间必须晚于当前时间才能点击"开始活动"
3. **结束保护**：活动结束后无法再添加/修改图书，防止数据混乱
4. **价格合理性**：预售价应低于原价，系统不强制校验但建议折扣不低于5折
5. **库存管理**：库存为0时用户无法下单，需及时补货
